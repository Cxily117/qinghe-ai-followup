这张表和智能体的关系

问答链路里，resolve_patient 工具就是查这张表

1. 医护在问答页说「张伟 髋关节术后 该随访几次」→ 模型调用 resolve_patient；
2. 工具用住院号或姓名 精确匹配 本表，唯一命中才返回患者上下文（科室、方案、出院日、术后天数）；
3. 命中多位同名或查不到 → 返回 found=false + 候选，模型只能回来问人，不许猜；
4. 停用的患者不参与匹配，相当于「这个人不该再被随访」。
