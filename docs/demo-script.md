# 演示脚本：制度怎么问，怎么讲给别人听

> 面向：第一次看这个系统的人（院里领导、医务处、信息科、评审专家）。
> 目标：8 分钟内让对方相信三件事——**无据不作答、写操作止步草稿、每句话都能回溯**。
> 这份文档分两部分：先讲「怎么问」，再讲「怎么讲」。

---

## 一、先搞清楚两个模式（问错模式，效果差一半）

页面顶部有一排切换：**问答** / **智能体**。

| | 问答（默认） | 智能体 |
|---|---|---|
| 干什么 | 检索已发布制度 → 依条文回答，带引用卡片 | 会调工具：查患者 → 多轮检索 → 跑规则校验 → 出待确认草稿 |
| 适合问 | 「制度要求什么」——节点、渠道、内容、红旗症状 | 「这个患者怎么样」「帮我建随访」「他胸痛怎么办」 |
| 屏幕上会看到 | 回答 + 来源卡片（可点开原文） | 左侧步骤时间线：`resolve_patient` → `search_policy` → `check_followup_rule` |
| 速度 | 3–8 秒 | 10–25 秒（多轮核对） |

**一句话记法：问制度用问答，问患者用智能体。**

## 二、可以直接照读的问题清单

下面每一问都标了"该看到什么"。演示时照着读，别临场编——模型对模糊问法很敏感。

### A. 制度条文类（问答模式，回答应带 [1][2] 引用）

**A1｜节点**
> 关节置换术后随访，制度要求哪些节点？

应看到：术后第 3 天出院前评估 / 第 14 天门诊复查 / 第 30、90 天康复科联合随访，句末带 `[1]`。
指给对方看：回答下方的**来源卡片**，点开就是《关节置换术后康复随访要求》原文片段。

**A2｜渠道与内容**
> 骨科术后随访，出院后第 7 天那次是电话还是门诊？要问哪些内容？

应看到：第 7 天电话随访（切口愈合、疼痛评分、活动能力），带 `[1]`。
价值点：它答的是**制度原文**，不是"一般来说"。

**A3｜跨文档**
> 冠心病 PCI 术后患者的随访节点，和骨科有什么不一样？

应看到：冠心病是 30/90/180 天，骨科是 7/14/30/90 天，两条引用分别指向两份文档。
价值点：**能同时引用两份制度**，编号不串（这是引用编号连续性的验收点）。

### B. 患者事实类（智能体模式，必须看到工具步骤）

**B1｜查患者**
> 住院号 ZY2026001 这位患者，出院多少天了？

应看到：左侧步骤里出现 `resolve_patient`，回答里患者姓名是**掩码**（张\*），带科室、术后天数。
指给对方看：管理后台 →「患者目录」，同一条记录在里面——**数据来自数据库表，不是模型记忆**。

**B2｜查不到（这一问最能建立信任）**
> 住院号 ZY9999999 这位患者什么时候随访？

应看到：`未找到唯一匹配的患者，请向医护核对住院号，不要猜测。`
价值点：**它宁可说查不到，也不编一个患者出来。**

**B3｜建随访（写操作闸门）**
> 帮我给 ZY2026001 新建随访：第 7 天电话、第 30 天门诊复查。

应看到：步骤依次是 `resolve_patient` → `search_policy` → `check_followup_rule`（passed=true）→ `create_followup_task_draft`，
最后弹出**待确认卡片**，文字明确写"确认前请勿声称已创建"。
指给对方看：此时去「质控报表」看草稿数——**没变**；点确认后才会 +1。
价值点：AI 只能写草稿，落库必须有人点。

### C. 边界类（用来证明"它知道自己的边界"）

**C1｜知识库没有的病种**
> 儿科哮喘出院后随访怎么做？

应看到：`随访规范中未查询到相关内容。`（无引用）
价值点：**没有的制度不硬答**。这是医疗场景最要紧的一条。

**C2｜诊疗问题**
> 伤口有点疼，布洛芬一次吃几片？

应看到：未查询到相关内容（或拒答 + 免责声明）。
价值点：它是**制度助手**，不是医生；用药剂量一律不答。

**C3｜红旗症状（智能体模式）**
> ZY2026003 王建国，腰椎术后第 7 天，切口红肿渗液还发烧 39 度。

应看到：先评估红旗（高风险）→ 给出"立即联系主管医生/急救"的处置 → 生成升级工单号，并说明"接手人待确认"。
价值点：处置动作**有制度出处**，不是"建议就医"这种通用话。

## 三、不要这样问（附解释，被问到时不慌）

| 别问 | 会发生什么 | 怎么解释 |
|---|---|---|
| 「随访一般怎么做？」 | 可能答得泛，或触发"未查询到" | 系统只按**已发布制度**答，"一般"没有出处。换成"制度要求什么" |
| 「张伟该随访几次？」 | 同名/模糊时返回"未找到唯一匹配" | 这是设计：宁可让医护补住院号，也不猜人 |
| 智能体模式下问「该安排哪些随访」 | 它会**直接做一张待确认草稿** | 它把"该安排"当成了建单意图。只想看条文就切回问答模式 |
| 问草案里的文档内容 | 答不准 | 知识库只有"已发布"才参与检索；草案在后台可见但不进检索（这条本身是卖点） |

## 四、8 分钟演示动线（照着走）

| 时间 | 做什么 | 说什么（一句） |
|---|---|---|
| 0:00 | 打开链接（带 sharecode），登录 | 「这是院内随访制度助手，服务对象是医护，不是患者。」 |
| 0:30 | 问答模式问 A1 | 「它只答制度里写过的东西，每条结论后面有编号。」点开来源卡片 |
| 1:30 | 问 C1（儿科哮喘） | 「制度里没有的，它直接说查不到——这一条比答对更重要。」 |
| 2:00 | 切智能体模式，问 B1 | 「换成患者问题，它要去查库。」指步骤里的 `resolve_patient` |
| 3:00 | 打开后台 → 患者目录 | 「刚查的患者就在这张表里，管理员可以自己加；停用的人它立刻查不到。」 |
| 4:00 | 回问答页，问 B3 | 「建随访它会先出草稿，等人点确认才落库。」指待确认卡片，不点 |
| 5:00 | 后台 → 对话审计 | 「刚才每一轮它想干什么、调了什么、参数是什么，都在这；住院号是脱敏存的。」 |
| 6:00 | 后台 → 质控报表 → 导出 CSV | 「无引用率、草稿确认率这些指标能直接导给质控。」 |

| 7:30 | 收尾 | 「现在是 MVP：能跑、能验、边界清楚。没接 HIS、没接院内通知，这五条写在验收单里。」 |

## 五、被追问时的三句实话（别硬撑）

1. **「患者数据是真的吗？」**
   → 不是。库里 4 位是演示患者（来源标记"演示"），字段与 HIS 对齐；接真实数据只需把 `patients` 表换成同步任务，上层不用改。

2. **「回答会不会编？」**
   → 会，任何大模型都会。所以我们做了三道：只允许引用已发布条文、没编号的回答打 `uncited_answer` 标记进质控报表、制度里没有的节点直接拦截改写。但它不是零风险，所以定稿仍要人看。

3. **「能上线吗？」**
   → 能演示，不能直接上生产。上线清单里还有 5 项安全阻断（默认密钥、限流、Cookie Secure、日志保留、恢复演练），这是路线图上的事，不是靠演示掩盖的事。
